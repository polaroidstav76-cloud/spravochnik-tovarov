Калькулятор карточек на листе

Материал входит в стоимость печати. Сотрудник выбирает готовый материал, а цена берётся из правила печати.

Калькулятор стоимости футболок

Розничная/оптовая цена определяется автоматически по количеству. Для нашей футболки оптовый порог считается по количеству футболок, для футболки клиента — по общему количеству нанесений.

Плоттерная резка

Цена берётся из «Цены листов» по цвету плёнки и размерной ступени: до 10×15, до 15×21, до 21×28, до 28×40, до 28×60, до 28×100 см. Изделие можно повернуть, оно попадает в самую маленькую подходящую ступень.

Цены на печать и услуги

Для каждой строки укажите размер листа, тираж от которого действует строка, цену розницы и цену опта. Калькулятор выбирает последнюю подходящую строку по количеству листов.

Добавить правило печати

Материал здесь является частью готовой цены печати. Например: глянец 30×42 — 190 ₽/лист. Дополнительно цена глянца к печати НЕ прибавляется.

Ламинация

Ламинация задаётся отдельным правилом: материал, размер листа, порог тиража и цена розницы/опта. Стоимость считается за лист.

Футболки — комбинации нанесений

Здесь администратор сам задаёт цену любой комбинации до 3 нанесений. Порядок нанесений не важен: ДТФ большой + плёнка маленькая и плёнка маленькая + ДТФ большой — одна и та же комбинация. Для опта укажите порог «Опт от». Для нашей футболки порог считается по количеству футболок, для футболки клиента — по общему количеству нанесений.

Услуги: «Разные картинки» и «Резка»

Стоимость услуги считается за лист. Для каждой услуги можно задать свои пороги и цены розницы/опта.

Плёнка для плоттерной резки

Для каждого цвета плёнки укажите цену одного изделия в каждой размерной ступени. Изделие попадает в самую маленькую ступень, в которую помещается (его можно повернуть). Пустая ступень — цены нет.

Продажи — настройка

Одна карточка товара/услуги содержит всё: наименование, розницу, опт по количеству, себестоимость, категорию и комментарий сотруднику.

Филиалы

Сотрудники

Сотрудник не привязан к филиалу и может работать где угодно.

Карточка товара / услуги

Например: от 10 шт — 10 ₽; от 30 шт — 8 ₽. Все пороги хранятся в этой же карточке.

Допродажи

Пример: Фото 21×30, количество 1–5 → предложить Фоторамку. При 100 фото подсказка не появится. Правила можно менять.

Ставки зарплаты

Ставка за смену может отличаться по филиалам. Ретушь получает только главный сотрудник смены.

Задания

«На филиал» показывается всем, кто работает на филиале в выбранный день. «На сотрудника» показывается ему на каждой смене на любом филиале, пока он не отметит выполнение.
