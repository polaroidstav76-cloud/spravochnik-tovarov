КЛАУДШОП — УЧЁТ КОМПЬЮТЕРОВ, версия 1.1

Обновление уже установленной программы:
1. Распакуйте весь ZIP в любую папку.
2. Запустите UPDATE.cmd и разрешите запрос администратора Windows.
3. Дождитесь «ГОТОВО». Код не нужен: прежнее подключение и защищённый токен сохраняются.
4. В Клаудшопе нажмите Ctrl+F5 → «Включения и опоздания» → «Обновить».
   У компьютера должна появиться версия 1.1.0. Установить обновление нужно на каждом ПК с учётом.

Первое подключение нового компьютера: INSTALL.cmd, одноразовый код из Клаудшопа.

Исправлено повторное использование старого времени запуска после гибернации / быстрого запуска.
Программа каждую минуту заново читает журнал Windows и сохраняет:
- загрузку Windows;
- выход из сна / гибернации;
- завершение работы Windows;
- переход в сон / гибернацию;
- обнаружение аварийного завершения (точное время пропадания питания неизвестно).

Выключение сохраняется в истории Клаудшопа, НО уведомления о выключении не отправляются.
Так как при выключении сеть может уже не работать, запись может появиться после следующего включения.
Пропадание интернета не считается выключением. Если Windows не сохранила событие, время не выдумывается.
Windows должна показывать правильные дату и время.

При обновлении читаются доступные события за последние 30 дней. Это может восстановить пропущенные
включения и выключения, если записи ещё есть в системном журнале. История и исключённые дни сохраняются.
Не нужно отключать устройство в Клаудшопе или удалять прежнюю программу перед обновлением.

Данные программы: C:\ProgramData\CloudshopAttendance. Журнал status.log не содержит токенов.
Удаление: UNINSTALL.cmd, затем отключение устройства в админке.
