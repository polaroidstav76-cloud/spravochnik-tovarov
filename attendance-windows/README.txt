КЛАУДШОП — ВКЛЮЧЕНИЯ И ОПОЗДАНИЯ, версия 1.0

Установить один раз на ОДНОМ основном компьютере каждого филиала.
Windows 10/11, встроенный Windows PowerShell 5.1. Python не нужен.

1. В Клаудшопе войдите как администратор, обновите страницу Ctrl+F5.
2. Откройте «Включения и опоздания» → «Подключение компьютеров».
3. Выберите филиал, включите учёт, проверьте начало/конец рабочего дня.
   По умолчанию учёт начинается завтра, чтобы день установки не считался опозданием.
   Для проверки сегодня можно выбрать сегодняшнюю дату. Нажмите «Сохранить настройки».
4. Нажмите «Получить код подключения» и скопируйте код (действует 15 минут).
5. Распакуйте ВЕСЬ ZIP, запустите INSTALL.cmd. Разрешите повышение прав Windows.
6. Вставьте код в окно установки, нажмите Enter. Дождитесь сообщения «ГОТОВО».
7. В Клаудшопе нажмите «Обновить». У компьютера появятся название, версия и время передачи.

Программа работает в фоне от SYSTEM и запускается при старте Windows.
Повторно запускать её ежедневно и открывать сайт не требуется.
Данные: C:\ProgramData\CloudshopAttendance. Обычный сотрудник не имеет доступа к токену.

В Telegram используется существующий бот Клаудшопа, получатель — администратор Рустам.
Только первое включение за день и отсутствие данных к началу работы (через 2 минуты).
Нет сообщений о выключении, работе после закрытия, проверках связи или потере интернета.
Если компьютер включился после закрытия — уведомления не будет.
Если компьютер не выключался на ночь, время прихода не определяется; день не входит в рейтинг.

Без интернета время включения сохраняется и передаётся позже. Если бот не получил данных,
его предупреждение не утверждает, что сотрудник точно опоздал.
Время берётся из событий загрузки Windows (включая быстрый запуск), а не времени запуска установщика.
На ПК должны быть правильные дата и время, желательно автоматическая синхронизация Windows.
Перезагрузки не меняют первое включение и не создают повторных сообщений.

В графике используется основной сотрудник (первая клетка филиала), только опубликованный месяц.
Помощник не считается опоздавшим по включению общего компьютера. Если нет однозначного
основного сотрудника, история хранится без персонального рейтинга.
Спорный день администратор может исключить из сравнения с комментарием.

Если компьютер уже подключён — не устанавливайте второй раз:
сначала «Отключить компьютер» в Клаудшопе, затем новый код.
Для удаления запустите UNINSTALL.cmd и отключите компьютер в Клаудшопе.
Журнал программы: C:\ProgramData\CloudshopAttendance\status.log (без токенов).
