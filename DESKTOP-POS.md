# Клаудшоп · касса для Windows

Первая версия 0.1.0 для Windows 10/11 x64. WebView2 + WinForms (.NET 8, self-contained). Программа открывает существующий Клаудшоп с `?desktop=1`; обычный сайт и база не дублируются. Установщик для текущего пользователя, без установки .NET, с проверкой подписи официального установщика WebView2. Готовый архив: https://github.com/polaroidstav76-cloud/spravochnik-tovarov/releases/download/desktop-pos-v0.1.0/Cloudshop-Desk-Windows-x64.zip

## Возможности
- Отдельное окно, закрепление поверх остальных, узкая панель, Ctrl+Shift+Space, необязательный автозапуск через HKCU.
- Та же касса/товары/цены/скидки/карты/варианты и оформление продаж. Компактное представление, поиск и избранное. Печать не запускает и страницы PDF не считает автоматически.
- Собственный профиль WebView2: войти нужно один раз на компьютере. Старые токены браузера не копируются, пароли в настройках не сохраняются.
- Черновик сохраняется в localStorage профиля текущего пользователя Windows, отдельный ключ для каждого логина. После сбоя позиции/комментарий/поля оплаты восстанавливаются; клубная карта проверяется заново через сервер, старый баланс не принимается на веру.
- Другой филиал/кассир не получают чужой черновик. Перенос в новую смену того же филиала только с подтверждением; берётся новый номер. Ошибка записи в локальное хранилище показывается, штатное закрытие предлагает не терять несохранённые данные.
- Перед sales_create_sale черновик отмечается как попытка оформления, подтверждённый успех очищает его. После неопределённого результата проверяется наличие продажи в той же смене/филиале по номеру до восстановления. Повторная продажа автоматически не создаётся.
- Для оплаты существующего заказа при получении после сбоя нужно открыть серверный заказ на полном сайте; такой черновик не превращается в новую продажу.

## Установка
Распаковать ZIP целиком → INSTALL.cmd → ярлык «Клаудшоп - Касса» → войти своим логином → выбрать свою смену → открыть продажу. Развёрнутые инструкции внутри README.txt. START.cmd запускает установленную копию, при отсутствии устанавливает. Удаление оставляет WebProfile с черновиками и входом; UNINSTALL.cmd удаляет программу/ярлыки/автозапуск. Перед обновлением завершить оформление и закрыть программу, установщик не убивает процесс и не сбрасывает кассу.

## Проверки и ограничения
GitHub Actions desktop-pos-build.yml собирает Windows exe, проверяет PowerShell-парсер и запуск `--self-test` на Windows, публикует ZIP+SHA256 в GitHub Release. Нативная проверка инициализирует WinForms/WebView2 control/панель; реальную печать и работу поверх Photoshop/PDF нужно проверить на рабочем ПК. В Linux-среде проверяются isolated mode, восстановление/изолированность, неопределённые записи и реальные DOM/CSS кассы в Chromium (`tests/desktop-pos.cjs`, `tests/desktop-pos-browser.cjs`). До фактической оплаты нужен интернет. Программа пока без сертификата подписи издателя.

Сборка вручную: `dotnet publish windows-pos/CloudshopDesk.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist/app`, затем добавить файлы установки из windows-pos и собрать ZIP. WebView2 SDK закреплён в csproj; runtime обновляется средствами Microsoft. Целевой сайт задан в Program.Site, до подключения Айпринта он не меняется.
