# Светлая и тёмная темы

Переключатель «Тёмная тема» / «Светлая тема» находится только на главном экране: в шапке сайта перед именем аккаунта
(тема → имя → выход) и на стартовом экране программы-окна. В окне продажи кнопки нет. Доступен сотруднику
без прав администратора. По умолчанию светлая тема; системная тема автоматически
не меняет привычный интерфейс. Выбор сохраняется в localStorage
`cloudshop.appearance.v1` этого браузера/профиля Windows, синхронизируется между
вкладками. В браузере и программе-окне профили независимы.

`theme.js` загружается до разметки для восстановления выбора без вспышки
светлого интерфейса. При недоступном localStorage переключатель продолжает
работать в текущем окне. `theme.css` переопределяет дизайн-токены, статические
компоненты и независимые модули. Для старых inline-цветов безопасно добавляются
альтернативные CSS-переменные без замены исходного светлого значения; MutationObserver
обрабатывает новые строки и окна. Таблицы Excel сохраняют исходные заливки;
у светлых ячеек остаётся тёмный текст. Фото, canvas, изображения, экспортированные
JPG/PDF и бизнес-данные не перекрашиваются. Только основной Клаудшоп владельца.

Проверки: `tests/theme-browser.cjs` — явный выбор, перезагрузка, вкладки, программа,
касса/поля/кнопки, динамическая строка со старым inline-оформлением, мобильная
ширина и печатная цветовая схема. Просмотрены снимки главного экрана и кассы.
