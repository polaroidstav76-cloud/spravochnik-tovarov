# Повторяющиеся задания

Только основной Клаудшоп. В «Настройки → Задания» доступны прежние разовые задания и повторения для сотрудника либо филиала.

- Каждые N дней, начиная с заданной даты (например, каждые 3 дня).
- Каждые N недель в выбранные дни недели.
- Каждые N месяцев указанного числа. Если такого числа в месяце нет, используется последний день; последующие месяцы возвращаются к исходному числу (31 января → 28/29 февраля → 31 марта).
- Необязательная дата окончания включительно.

Новый шаблон не создаёт задания задним числом: используется ближайший подходящий день от сегодняшней московской даты, с сохранением исходной привязки расписания. При пропуске работы планировщика создаются пропущенные повторения с исходными датами. Генератор ограничен 500 новыми заданиями за один проход и 64 повторениями одного правила; остаток обрабатывается следующим запуском. Уникальные ключи и блокировки исключают дубли при повторном/одновременном запуске.

`pg_cron` запускает генератор каждые 5 минут; открытый сайт не требуется. Дополнительно генератор вызывается при проверке заданий смены и обновлении панели. Настройка шаблонов доступна только администратору; сотрудник не может создавать или менять правила.

Каждое повторение — отдельное задание в существующих таблицах с самостоятельным выполнением. Невыполненные личные задания, как раньше, переносятся на следующие смены сотрудника. Невыполненные повторяющиеся задания филиала также видны после своей даты. Выполнение такого задания филиала закрывает его для всех последующих смен этого филиала. Поведение разовых заданий филиала не меняется.

Приостановка запрещает создание новых повторений, сохраняя уже опубликованные задания. Возобновление начинается с ближайшего срока и не создаёт задания за время паузы. Редактирование меняет будущие повторения, не переписывает уже созданные задания и отметки выполнения. Отдельный опубликованный экземпляр можно удалить обычной кнопкой, не останавливая расписание. Для отключённого сотрудника/филиала правило автоматически приостанавливается.

В списке правил доступны редактирование, пауза/возобновление, дата следующего задания и последние 8 повторений с состоянием выполнения. Конфликт одновременных правок защищён версией. Одно повторение выполняется один раз независимо от количества открытых смен.

Схема: `task_recurrence.sql` (первоначальная установка). UI: `task-recurrence.js`. Изменения основной страницы сохраняют CRLF. Проверки: `tests/task-recurrence-db.cjs`, `tests/task-recurrence-ui.cjs`, `tests/task-recurrence-rollback.sql` (рабочая база, транзакция с откатом). Доступ извне к закрытым таблицам и внутреннему генератору отсутствует. Рассылка сообщений не добавлялась.
