# Промокоды и предупреждения перед оплатой

Только основной Клаудшоп; настройки и сайт Айпринта не изменяются.

В настройках продаж: **Промокоды и предупреждения**.

Промокод: код, название, срок (время интерфейса — местное время компьютера), тип:

- процент на весь чек;
- фиксированная сумма на чек, не больше суммы чека;
- процент на выбранные товары;
- бесплатный товар с заданным количеством.

Код применяется один раз на клубную карту, только один код на продажу, без списания баллов и без дополнительной ручной скидки. Новую клубную карту сначала сохраняют через клубные карты. Определение использованной акции сохраняется; отключение не меняет старые продажи. Возврат/удаление продажи не освобождает использованный код.

«Только розничные цены» при наличии опта показывает сотруднику оба варианта. Сотрудник выбирает. При скидке на выбранные товары остальные позиции сохраняют свою оптовую цену. Бесплатное количество выделяется отдельной строкой по 0 ₽; если товара не хватает в корзине, недостающее количество добавляется. Для подарка с вариантами нужно предварительно выбрать размер/цвет. Чтобы изменить состав после применения, убрать промокод, изменить товары, применить заново.

Промокод применяется при оплате, не при создании неоплаченного заказа «при получении». Начисление баллов сохраняет существующую схему программы; совместное списание запрещено. При неопределённом ответе сети повтор в той же форме использует прежний UUID, исключая дубль. Промопродажи не записываются в офлайн-очередь без ответа сервера. Настольные черновики хранят сведения об акции и проверяют её заново при восстановлении.

Предупреждение: конкретный товар, минимальное суммарное количество (включая все его варианты), текст, режим «предупреждение сотруднику» или «сообщение клиенту с копированием». Перед оплатой требуется «Ознакомлен». Сервер проверяет версию правила. В офлайне используются предварительно сохранённые правила; при синхронизации сервер проверяет их ещё раз.

Продажи за сегодня: **Редактировать** рядом с возвратом. Товары, количества, цены, оплата, скидка, баллы и комментарий меняются одной транзакцией; сохраняются номер, исходный кассир, журнал правок, корректируются склад, платежи, долги, баллы и уже перенесённый автоматический отчёт. Продажу с возвратом редактировать нельзя. При одновременном редактировании второй сотрудник получает просьбу открыть актуальную версию. Для акции используются сохранённые исходные условия, даже если она уже отключена; перед сохранением показывается новая сумма.
