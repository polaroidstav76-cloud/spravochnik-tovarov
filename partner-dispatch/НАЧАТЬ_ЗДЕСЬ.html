Первый запуск

Это готовая программа для Windows 10/11. Аренда сервера, установка Python и платная подписка не нужны. Для файлов и ZIP используется свободное место вашего компьютера и Яндекс Диска.

  1. Распакуйте весь архив в постоянную папку. Не запускайте программу прямо из ZIP.
  2. Откройте START.cmd. Он выберет подходящую 32- или 64-разрядную версию. Можно запустить соответствующий EXE напрямую.
  3. В программе откройте вкладку «Первый запуск». Мастер проведёт по боту, Telegram API, Диску и почте.
  4. Бот: @perezakazi_bot. Токен вводится в программе. Пароли, API hash, OAuth-токен и файл сессии не отправляйте в переписку.
  5. Для проверки введите свой тестовый email, затем отправьте безопасный тестовый TIF. Встроенный файл ТЕСТ_НЕ_ПЕЧАТАТЬ_1х1см.tif уже находится в комплекте.
  6. Проверьте три кнопки: просмотр названий, срочную отправку, удаление. До подтверждения теста письма помечены ТЕСТ.
  7. Найдите письмо, скачайте ZIP и откройте исходный TIF. Только затем подтвердите тест в программе и включите расписание 18:00 МСК.

Что потребуется от ваших аккаунтов

  • Токен отдельного бота от BotFather.
  • Telegram API ID и API hash для приёма больших файлов. Личный Telegram-аккаунт программой не автоматизируется.
  • OAuth-токен вашего приложения Яндекс Диска. В мастере есть ссылки и отдельная кнопка получения токена по ClientID.
  • Адрес отправителя и пароль приложения Яндекс Почты. Основной пароль не требуется.

Рабочие правила

Сначала выбирается направление. Сейчас работает широкоформатная печать, ДТФ пока не настроена и файлов не принимает. Файлы после 18:00 относятся к следующему дню. Срочная кнопка отправляет текущую очередь выбранного направления.

Файл принят только после сообщения «Сохранён». Компьютер должен быть включён, подключён к интернету и не спать до окончания отправки. После начала передачи письма почтовому серверу отозвать файл нельзя. При неопределённом ответе почты автоматический повтор остановится для ручной проверки.

Архив скачивается по ссылке: любой получивший её сможет скачать файлы. Успешно отправленные архивы и оригиналы автоматически не удаляются; следите за свободным местом. В отчёт проверки не попадают токены, почтовые адреса и имена файлов.

Программа не подписана сертификатом коммерческого издателя. Если Windows или антивирус её блокирует, не отключайте защиту: зафиксируйте точный текст сообщения и обратитесь за сопровождением. Живую отправку и доступы проверяем на вашем компьютере. Подтверждение SMTP означает принятие письма сервером, а не прочтение адресатом.
