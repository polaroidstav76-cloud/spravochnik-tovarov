ГОТОВЫЙ EXE — РЕКОМЕНДУЕМЫЙ СПОСОБ
В новом архиве Cloudshop-Print-Windows-v0.3.zip уже есть обе версии EXE.
Распакуйте весь архив, откройте НАЧАТЬ_ЗДЕСЬ.html и запустите START.cmd.
Python устанавливать не требуется. Мастер «Первый запуск» покажет все шаги.
По умолчанию расписание выключено; до подтверждения первого теста письма
помечаются ТЕСТ. После проверки письма и ZIP подтвердите тест в программе.
Смена адресов или доступов требует нового теста и отключает расписание.
Тестовый TIF в комплекте: ТЕСТ_НЕ_ПЕЧАТАТЬ_1х1см.tif — только для проверки.
Для вашего тестового адреса заполните поле «Получатель» на компьютере.
Секреты и адреса не входят в публичную сборку программы.
Кнопка «Отчёт без секретов» поможет передать состояние проверки без токенов,
почтовых адресов, имён файлов и команд подключения сотрудников.

ДАЛЕЕ — ПОДРОБНЫЕ ШАГИ И ЗАПУСК ИСХОДНОЙ PYTHON-ВЕРСИИ (ЕСЛИ ПОТРЕБУЕТСЯ).

КЛАУДШОП — ШИРОКОФОРМАТНАЯ ПЕЧАТЬ
Версия 0.3 — установка и тестовая проверка

Программа подготовлена для Windows 10/11 и отдельного @perezakazi_bot.
Главное меню: «Широкоформатная печать» и «ДТФ-печать».
Пока подключается только широкоформатная печать; ДТФ явно помечена
как ненастроенная и не принимает файлы. Будущие направления имеют отдельные
очереди; просмотр, отправка и удаление относятся к выбранному разделу.
Перед первым файлом сотрудник обязательно выбирает направление.
Кнопка «Назад» возвращает в главное меню.
Программа подготовлена для Windows 10/11. На вашем компьютере её ещё нужно
установить, подключить бота, Диск и почту и проверить реальную отправку.
Проверка без ваших аккаунтов не подтверждает доставку настоящего письма.

ЧТО ДЕЛАЕТ
• Принимает документы TIF/TIFF/PDF/JPG/PNG размером до 500 МБ.
• Сохраняет оригинальные байты, название, принадлежность к филиалу.
• В 18:00 МСК собирает ZIP, загружает его на ваш Яндекс Диск и отправляет ссылку
  по почте. Первоначальный получатель — ваш тестовый адрес (введите при настройке).
• Уведомляет Telegram после принятия письма почтовым сервером.
  Это не подтверждение, что адресат прочитал письмо или получил его во «Входящие».
• Кнопка «Загруженные файлы» показывает текущие файлы, филиалы и копии ДТФ.
• Кнопка «Отправить сейчас» отправляет текущую очередь выбранного направления со всех филиалов.
  Она работает даже при выключенной ежедневной отправке — это удобно для теста.
• «Удалить файл» позволяет любому подключённому сотруднику убрать ошибочный файл,
  в том числе во время скачивания, сборки и загрузки ZIP. Архив пересобирается.
• После начала передачи письма SMTP-серверу отменить его уже нельзя. В этот момент
  удаление блокируется. При неоднозначном ответе почты нужен контроль владельца.

Первый запуск НЕ включает автоматическую ежедневную отправку.
Она включается отдельной галочкой после вашего теста.
Не используйте старого бота закупок, сводки или другой действующей системы.

ШАГ 1. УСТАНОВКА
1. Распакуйте ВЕСЬ ZIP в постоянную папку, например C:\CloudshopPrint.
   Не запускайте программу прямо внутри ZIP, из сетевой папки или папки общего доступа.
2. Нужен Python 3.11 или новее для Windows с Tcl/Tk и Python Launcher.
   Официальная страница: https://www.python.org/downloads/windows/
   Пароли и коды подтверждения при установке вводить не требуется.
3. Дважды щёлкните SETUP.cmd. Зависимости находятся в wheelhouse; эта установка
   не скачивает пакеты из интернета. Их версии и SHA256 зафиксированы в requirements.lock.
4. Запустите DIAGNOSTICS.cmd. Он проверит Python, Tk и шифрование Windows DPAPI.
   Не проверяет почту, не отправляет письма и не выводит секреты.
5. Запустите START.cmd. Откроется окно программы.

ШАГ 2. ОТДЕЛЬНЫЙ БОТ
1. В Telegram откройте проверенного @BotFather: https://t.me/BotFather
2. Отправьте /newbot. Задайте имя и username нового бота.
3. Токен скопируйте непосредственно в поле «Токен отдельного бота» в программе.
   Не присылайте токен, API hash, пароль почты или OAuth-токен в чат.
4. Для получения больших файлов программа использует Telegram API через Telethon,
   с авторизацией только БОТА. Это не автоматизация вашего личного Telegram-аккаунта.
   Отдельный локальный Bot API Server и Docker устанавливать не требуется.
5. На https://my.telegram.org/apps войдите самостоятельно и создайте приложение
   в API development tools. Можно назвать его Cloudshop Print Dispatch,
   выбрать Desktop и описание «Приём макетов и отправка заказов фотоцентра».
   Перенесите api_id и api_hash в поля Telegram API ID и Telegram API hash.
   Вход на этом официальном сайте нужен для регистрации приложения. Программа
   не просит номер телефона, пароль личного Telegram или код входа.
   Если Telegram не даёт зарегистрировать приложение — сообщите точный текст ошибки,
   без кодов входа, токенов и API hash; дальше разберём вместе.

ШАГ 3. ЯНДЕКС ДИСК
1. Программа использует уже имеющееся место вашего Диска, подписку не покупает.
   Один макет может весить 500 МБ; предварительно проверьте свободное место.
2. Для REST API нужен OAuth-токен вашего приложения Яндекс Диска.
   Регистрация: https://oauth.yandex.ru/client/new
   Инструкция: https://yandex.ru/dev/disk/rest/
   Запросите права Диска, необходимые для чтения/проверки метаданных, записи,
   публикации архива и удаления созданных программой временных архивов.
   Названия и шаги интерфейса Яндекса могут изменяться; при настройке идём по экрану.
3. Полученный токен введите в программе, в поле «OAuth-токен Яндекс Диска».
4. Архивы создаются в отдельной папке Cloudshop-Print. Для отправки создаётся
   публичная ссылка: любой человек, который её получил, сможет скачать архив.
   Сами файлы из разных филиалов не публикуются по одному.
5. Успешно отправленные архивы и оригиналы автоматически НЕ УДАЛЯЮТСЯ.
   Правила хранения и очистки согласуем после теста. При заполнении диска
   программа оставляет очередь на компьютере и сообщает об ошибке.
   Неотправленный ZIP, состав которого изменили удалением файла, убирается
   из созданной программой папки в корзину Диска и формируется заново.

ШАГ 4. ПОЧТА
1. В поле «Получатель» укажите ваш тестовый почтовый адрес.
2. В поле «Отправитель» укажите свой Яндекс-ящик, с которого
   разрешаете отправку. Вход SMTP должен соответствовать адресу отправителя.
3. В настройках Яндекс ID создайте отдельный пароль приложения для почты:
   https://id.yandex.ru/security/app-passwords
   При необходимости включите доступ почтовых программ в настройках Яндекс Почты.
   Основной пароль от аккаунта в программу не вводите.
4. Введите пароль приложения в поле «Пароль приложения Яндекс Почты».
5. Нажмите «Сохранить настройки», затем «Проверить Диск и почту (без отправки)».
   Сервер SMTP фиксирован: smtp.yandex.ru:465 с проверкой TLS-сертификата.
   Отправка писем не начинается от этой проверки.

ШАГ 5. ПОДКЛЮЧЕНИЕ И ТЕСТ
1. Нажмите «Запустить бота», затем «Подключить сотрудников».
2. Сначала сами отправьте НОВОМУ боту показанную команду /owner с вашим кодом.
3. Выдайте сотрудникам команду /join с кодом сотрудников и названием филиала.
   Код владельца не передавайте. Подключённые сотрудники смогут видеть названия
   всей очереди, удалять любой ещё не отправленный файл и запускать общую отправку.
4. Выберите «Широкоформатная печать», затем «Загрузить файл».
   Загрузите безопасный тестовый TIF как документ, без сжатия.
   Файл принят только после ответа «Сохранён». До этого дождитесь скачивания.
5. Проверьте кнопки просмотра и удаления на ненужном тестовом файле.
6. Загрузите тест снова и нажмите «Отправить сейчас».
7. Проверьте письмо в тестовом ящике (включая «Спам»), скачайте ZIP по ссылке,
   распакуйте и откройте TIF. Сравните размер, название и содержимое с оригиналом.
8. Только после успешного теста включите галочку ежедневной отправки в 18:00.
   Адрес партнёра меняется в «Настройках» после остановки обработчика.

РАБОЧИЙ РЕЖИМ
• Один компьютер работает каждый день с 10:00 до 20:00; он должен оставаться
  включённым с интернетом и без сна, пока вся отправка не завершится.
• 18:00 — начало подготовки, а не гарантия доставки письма ровно в эту секунду.
  Передача нескольких больших файлов может занять время.
• Файлы, отправленные в Telegram начиная с 18:00 МСК, относятся к следующему дню.
  Кнопка срочной отправки может отправить их раньше, по вашему действию.
• Новые файлы после нажатия «Отправить сейчас» остаются для следующей отправки.
• При включении после пропущенного времени автоматическая отправка накопленной
  очереди происходит после 18:00; если запустили утром — ждёт 18:00 либо команды.
• Закрытие окна останавливает обработчик. Сворачивание не останавливает его.
• «Автозапуск при входе Windows» добавляет запуск только для текущего пользователя.
  Это не служба: до входа пользователя программа не работает. Повторное нажатие
  позволяет отключить автозапуск. Не перемещайте папку программы после включения.
• Telegram не гарантирует бессрочное хранение неполученных обновлений для бота.
  После длительного отключения проверяйте подтверждение каждого файла «Сохранён».
• При сетевой ошибке скачивание и подготовка повторяются. Если скачивание
  исчерпало попытки, удалите проблемную запись и отправьте исходный документ заново.
• Если SMTP-сервер мог принять письмо, но ответ потерялся, повтор остановится.
  Проверьте ящик и нажмите в программе «Проверить неопределённое письмо».
  Отмечайте «Нет» только после проверки — ручной повтор может создать дубль.
• Ключи настроек шифруются DPAPI текущего пользователя Windows. Сессия Telegram
  хранится в отдельной SQLite-базе в защищённой папке этого пользователя.
  Не публикуйте и не пересылайте папку данных, настройки или файл сессии.
• Настройки и очередь: %LOCALAPPDATA%\CloudshopPrintDispatch.
  Открыть можно кнопкой в программе. Не удаляйте SQLite-файлы очереди или сессии.
• Резервную копию папки данных делайте только при остановленном обработчике.
  DPAPI-настройки не переносятся автоматически на другого пользователя/компьютер.

ЧТО ПРОВЕРЕНО ПРИ ПОДГОТОВКЕ
Локальные автоматические тесты: файл 500 МиБ, сохранение оригинальных байтов,
совпадающие названия, граница 18:00, удаление во время загрузки ZIP, запрет
удаления после начала SMTP, остановка повторов при неоднозначном ответе,
восстановление очереди после перезапуска, отсутствие повторных уведомлений владельцу.
Тесты сетевых сценариев используют подставные Диск/SMTP/Telegram.
DPAPI, права папки, очередь и запуск окна проверяются автоматическими тестами
Windows. Готовый EXE дополнительно проходит автономный smoke test.
Живая отправка с ваших аккаунтов, автозапуск и доступность из сети филиала
проверяются на выбранном Windows 10 перед рабочим использованием.
TEST.cmd запускает локальные тесты, не отправляя писем и не подключаясь к аккаунтам.

СУЩЕСТВУЮЩИЙ КЛАУДШОП И ЕГО БОТ ЭТОЙ ПРОГРАММОЙ НЕ ИЗМЕНЯЮТСЯ.


История и уведомления (версия 0.3.4)
Во вкладке «История и уведомления» видны до 500 последних заказов, состояния,
количество файлов и получатель. Выберите отправленный заказ для открытия или
копирования ссылки. Приём письма сервером не подтверждает доставку партнёру.
Укажите название ответственного филиала и порог свободного места в ГБ,
нажмите «Сохранить уведомления». Пустой филиал означает уведомления только владельцу.
Остановите и снова запустите бота, затем откройте «Подключить сотрудников» и
скопируйте отдельную команду ответственного филиала. Выдавайте её только его сотрудникам.
Самостоятельное указание названия филиала через обычный /join не даёт этих прав.
Проверка места выполняется раз в час, уведомление о нехватке — один раз до восстановления места.
При сбое отправки придёт уведомление; после успешной отправки — подтверждение со ссылкой.
Если интернета нет, уведомления доставляются после восстановления связи при работающей программе.
Ручная отправка реализована во вкладке бота «Ручная отправка» для владельца и отдельно подключённых ответственных сотрудников.


Версия 0.4 — общая очередь и ручная отправка
Начиная с 0.9 рассылка при изменении очереди отключена. Список доступен по
кнопке «Загруженные файлы». Напоминание всем приходит за 30 минут до расписания.
Название уже ожидающего файла нельзя использовать повторно (регистр букв не учитывается).
После завершения заказа название можно использовать снова.
«Отправить сейчас» требует подтверждения. Если очередь изменилась за 5 минут
после запроса, подтвердите новый состав. Один запрос нельзя использовать повторно.
«Состояние» показывает очередь, подготовку, время повтора и расписание.
В «История и уведомления» задаются предупреждения о долгом скачивании (15 минут)
и долгой отправке после начала подготовки (30 минут). Ожидание расписания не считается сбоем.
При сбое автоповторы сохраняются. «Взять отправку вручную» или «Ручная отправка»
позволяет ответственному взять заказ, ожидающий повтора; это атомарно останавливает
автоматическую отправку. Во время загрузки архива/передачи письма взять заказ нельзя.
Заказ выполняет только взявший сотрудник. Он получит ссылку на готовый архив или
запросит все оригиналы документами в Telegram. Если ссылки нет, нужно скачать оригиналы,
собрать Полароид.zip с папкой Полароид и самостоятельно отправить ссылку получателю.
«Отправлено вручную» с подтверждением означает, что сотрудник уже отправил заказ;
кнопка сама письма не отправляет. Автоматического повтора завершённого заказа не будет.
При неопределённом результате SMTP сначала проверьте почту: «Письмо найдено» либо
«Письма нет — ручная отправка». Не допускайте повторного заказа партнёру.
Удаление из ручного заказа меняет версию состава: старые кнопки и ссылка недействительны.
Скачанные ранее исходники удалённого файла нельзя включать в ручной архив.
Уведомления не могут прийти при выключенном компьютере или полном отсутствии интернета.


Версия 0.5 — ДТФ-печать
В боте выберите «ДТФ-печать», отправьте PNG/TIF/JPG документом и укажите число копий.
Каждый исходник должен иметь правильный физический размер и записанный DPI (обычно 300).
Если DPI нет или TIFF многостраничный, пересохраните макет. PDF нужно экспортировать в PNG.
Кнопка «Количество копий» меняет число от 1 до 999 до начала формирования заказа.
Без указания числа копий отправка ДТФ не начинается. Сотрудник меняет свои принты,
владелец — любые. Одинаковые названия запрещены внутри одного направления очереди.
Физический размер сохраняется, принты не уменьшаются для подгонки по ширине.
Сборщик использует прямоугольные границы файлов, допускает поворот 90°, не зеркалит.
Прозрачные поля внутри самого исходника сохраняются; белый фон автоматически не удаляется.
Холст шириной 56 см, рабочая область 55 см, поля по 5 мм (с округлением до пикселя).
Минимальная длина холста остаётся 50 см. Прозрачный хвост сохраняется.
Промежуток выбирается от 5 до 20 мм с приоритетом меньшей длины; если всё не помещается,
высота увеличивается. Итог — Полароид-ДТФ.png, RGB с альфа-каналом, 300 dpi.
Сборка выполняется полосами, но нужны свободное место на компьютере и время обработки.
Один принт не должен превышать 80 миллионов пикселей, до 5000 копий в одном заказе.
Во вкладке «ДТФ-печать» укажите свою тестовую почту и сохраните её при остановленном боте.
Расписание ДТФ независимо от широкоформатной печати: по умолчанию Пн и Чт в 12:00 МСК,
оно выключено до тестовой отправки. Время и дни меняются прямо на вкладке ДТФ.
Для проверки отправьте ТЕСТ_ДТФ_10х15см.png из архива программы, укажите 2 копии,
нажмите «Отправить сейчас» и подтвердите. На тестовую почту придёт ссылка на PNG.
Проверьте количество, размеры, DPI и прозрачность в графическом редакторе, затем нажмите
«Тестовое письмо ДТФ проверено». Только после этого включайте расписание ДТФ.
Получатель ДТФ, расписание и подтверждение теста хранятся отдельно от широкоформатной печати.

Версия 0.6 — Мастерская и 30×40
Мастерская: после сохранения каждый файл отдельно отправляется на настроенную почту
ссылкой на оригинал. ZIP и расписание не используются. Пока укажите свою тестовую почту.
30×40: основная программа передаёт оригиналы на Яндекс Диск и ставит задания приёмнику.
На компьютере с принтером распакуйте тот же архив и запустите START-30X40.cmd.
Это отдельный режим без Telegram-сессии, токена бота и пароля почты.
В Клаудшопе войдите как администратор, нажмите «30×40». Создайте код основной программы,
вставьте его во вкладку «Мастерская и 30×40» при остановленном боте. Создайте отдельный
код приёмника, вставьте его в приёмнике на компьютере с принтером. Коды действуют 15 минут.
Активен один передатчик и один приёмник. Новое подключение режима отключает прежнее.
В приёмнике по умолчанию выбрана папка «30х40» на рабочем столе текущего пользователя,
включая перенесённый в OneDrive рабочий стол. Папку можно выбрать самостоятельно.
Нажмите «Запустить приёмник», затем настройте его автозапуск при входе в Windows.
Принтер автоматически не запускается. Сотрудник открывает сохранённый файл и печатает.
Уведомление в Клаудшопе появляется только после атомарного сохранения и проверки SHA256.
Оно видно вошедшим сотрудникам открытой смены филиала с принтером. Если сайт закрыт,
непрочитанное уведомление появится при следующем открытии сайта и смены.
Если компьютер/интернет выключен, задание ждёт. Не запускайте вторую копию Telegram-бота.
Сбой скачивания повторяется через 10 минут. Потерянное подтверждение повторяется отдельно,
без повторного скачивания. При совпадении имени старый файл не перезаписывается:
новый оригинал сохраняется в подпапке «Заказ-ID» с исходным названием.
Не меняйте папку приёмника, пока есть неподтверждённые сохранения. Не удаляйте файлы
на Диске, ожидающие приёмника. Задание, переданное приёмнику, нельзя удалить из бота;
полученную копию при необходимости удаляют вручную на компьютере с принтером.

ОБНОВЛЕНИЕ 0.7 — ФОРМАТЫ И КАРТОЧКИ
Широкоформатная — TIF/TIFF. ДТФ — PNG, PSD, TIF/TIFF. 30×40 — JPG/JPEG/PNG. Мастерская — любые файлы до 500 МБ. Неподходящее расширение не попадает в очередь. Подмена формата или повреждённый ДТФ после проверки убирается автоматически.
PSD сохраняйте с совместимостью Photoshop (сводное изображение), физическим размером и DPI. Слоёный PSD читается по сводному изображению.
В ДТФ по умолчанию одна копия; менять количество нужно только при необходимости. Одинаковые имена разрешены: выбирайте по номеру файла.
Загрузка, архивация, формирование холста и передача на Диск показываются обновлением карточки. Проценты измеряются по фактическим байтам/строкам холста/числу файлов. Предпросмотр ДТФ не является печатным исходником.
За 15 минут до плановой отправки на Тухачевского 26/10 в Клаудшопе будет напоминание о VPN на 30 минут. Для этого основная программа должна быть подключена к Клаудшопу (тот же код основного компьютера в разделе 30×40). В программе откройте вкладку 30×40, вставьте код и нажмите «Подключить основную программу». Получатели и тестовый режим при обновлении не меняются.
ОБНОВЛЕНИЕ: остановите бота, закройте программу, распакуйте новую версию в прежнюю папку с заменой файлов. Доступы, сотрудники и очередь хранятся отдельно в AppData и сохранятся. Затем запустите START.cmd.

ОБНОВЛЕНИЕ 0.8 — АВТОЗАПУСК В ФОНЕ
Откройте START.cmd → «Очередь и отправка» → «Автозапуск в фоне» → подтвердите. После входа этого пользователя в Windows бот запустится сам, окно открывать не нужно. Учетная запись должна быть та же, под которой сохранены настройки. До входа в Windows запуск невозможен: доступы защищены профилем пользователя.
После включения можно закрыть окно крестиком — бот останется работать. START.cmd снова покажет управление работающим ботом. Кнопка «Остановить» останавливает бота до ручного запуска; «Завершить программу» полностью выходит до следующего входа Windows. Для отмены автозапуска нажмите ту же кнопку повторно.
Если пропала связь — повтор подключения через минуту. Планировщик также перезапускает аварийно завершившийся фоновый процесс. Во время неподтверждённой передачи письма автоматический повтор не выполняется, чтобы не отправить дубль.
Папка с EXE должна оставаться на месте. После переноса папки выключите и снова включите автозапуск. Компьютер должен оставаться включённым, доступ в интернет и при необходимости VPN должны работать. Автозапуск не включает VPN за вас.


ОБНОВЛЕНИЕ 0.9 — НАПОМИНАНИЯ И УДОБНАЯ ОЧЕРЕДЬ
При добавлении и удалении файлов общих рассылок больше нет. Загрузивший сотрудник
по-прежнему видит получение и подтверждение сохранения своего файла.
За 30 минут до отправки по расписанию все подключённые Telegram-аккаунты получают
одно напоминание для направления Широкоформатная печать или ДТФ-печать, даже если
очередь пуста. Время и дни берутся из настроек программы, время московское.
При позднем запуске в последние 30 минут до отправки указывается фактически
оставшееся число минут. Доставка сохраняется между перезапусками; временный сбой
связи повторяется только для ещё не уведомлённых аккаунтов до времени отправки.

«Загруженные файлы» — текущие файлы выбранного направления, филиалы, состояние,
а для ДТФ количество копий. После отправки список актуализируется по запросу.
«Ближайшая отправка» — дата, день недели, время МСК, число файлов и состояние.
«Отменить последнюю загрузку» — отмена своего последнего неотправленного файла
с подтверждением. После включения файла в отправку кнопка его уже не отменяет.
Обычная кнопка «Удалить файл» остаётся для просмотра и удаления других позиций.
Повторная кнопка «Отправить сейчас» не создаёт дубль обрабатываемого заказа.

Этапы: 1/4 собираем заказ, 2/4 архивируем или формируем холст, 3/4 загружаем
на Диск, 4/4 отправляем письмо. Итог — «Заказ отправлен» и количество файлов.
Подтверждение получения партнёром не требуется и не упоминается.
При однозначном сбое подготовки или отказе почтового сервера файлы сохраняются,
повторная попытка — через 10 минут. Если связь оборвалась уже при передаче письма
и результат невозможно определить, повтор приостанавливается для защиты от дубля:
сначала проверьте почту, затем действуйте через существующую ручную отправку.

ОБНОВЛЕНИЕ УСТАНОВЛЕННОЙ ПРОГРАММЫ
1. Остановите обработчик в программе, дождитесь остановки и закройте окно.
2. Сохраните резервную копию прежней папки программы и её папки данных.
3. Распакуйте новый архив полностью и замените файлы в прежней папке программы.
   Папку данных не удаляйте. Запускайте обновлённый START.cmd из прежней папки.
4. Убедитесь, что открылась версия 0.9 и сохранились очередь/сотрудники/расписание.
5. На этом же компьютере профиль данных и шифрование Windows сохраняются.
При переносе на другой ПК секреты DPAPI потребуется ввести заново.
Не запускайте один Telegram-бот одновременно на двух компьютерах.


ОБНОВЛЕНИЕ 0.9.1 — ПОЛУЧЕНИЕ ССЫЛКИ ЯНДЕКС ДИСКА
После подтверждения загрузки и проверки контрольной суммы программа публикует
архив и ожидает публичную ссылку до минуты с повторными проверками. Временное
отсутствие public_url сразу после публикации больше не считается мгновенной ошибкой.
Повторные проверки ссылки не загружают архив повторно и не отправляют письмо.
При временных ошибках связи/429/5xx получение ссылки повторяется. Ошибки прав
доступа не маскируются. Если ссылка так и не выдана, заказ сохраняется и следует
обычному повтору через 10 минут; сообщение теперь уточняет, что архив уже загружен.
Обновление на том же ПК сохраняет очередь, сотрудников и защищённые настройки.


ОБНОВЛЕНИЕ 0.9.2 — ЭКОНОМИЯ ДЛИНЫ ДТФ
Сборщик сравнивает несколько порядков размещения и варианты с поворотом на 90°.
Добавлена стратегия минимальной занятой высоты. Сначала выбирается меньшая длина,
а больший промежуток — только при одинаковой длине. Для небольших заказов
проверяются все порядки размещения (до четырёх макетов). Размеры исходников
не изменяются: поворот выполняется без масштабирования и зеркалирования.
Ширина PNG 56 см, рабочая ширина 55 см, поля по 5 мм с округлением в пикселях.
Итоговый PNG имеет длину не менее 50 см. Хвост после последнего принта не обрезается.
Прозрачные поля внутри отдельных исходников автоматически не обрезаются.
В проверке макет 10×15 см и два 15×10 см размещаются одним горизонтальным рядом
с занятой высотой около 10 см на стандартном холсте 56×50 см. Если принты
не помещаются на 50 см, длина увеличивается. Приоритет — меньшая занятая высота,
чтобы не наращивать холст из-за неудачного поворота. PNG остаётся RGBA, 300 dpi.
Результат эвристический: выбирается лучший из проверенных вариантов раскладки.
Старые уже отправленные холсты не изменяются и повторно автоматически не
отправляются. Для них нужно сформировать новый заказ из исходных файлов.


ОБНОВЛЕНИЕ 0.10 — ПРОВЕРКА И ЗАМЕНА ГОТОВОГО ХОЛСТА ДТФ
Минимальный холст остаётся 56×50 см, хвост не обрезается. Исправление более
компактной раскладки и поворотов из 0.9.2 включено.

1. В момент отправки бот собирает ДТФ-холст и показывает предпросмотр.
2. Только после успешной доставки первого предпросмотра начинается таймер 5 минут.
   Если ничего не нажимать, бот отправит заказ автоматически через 5 минут.
3. «Скачать PNG» выдаёт полноразмерный файл документом, без сжатия Telegram.
4. «Исправить макет» немедленно приостанавливает автоотправку этого заказа и
   закрепляет редактирование за нажавшим сотрудником. Второй сотрудник не может
   одновременно заменить этот холст. Пауза сохраняется после перезапуска программы.
5. Сотрудник правит файл и отправляет его обратно документом в тот же бот.
   Требования: настоящий PNG, ширина 56 см (6614 px), длина не меньше 50 см
   (5906 px), 300 dpi по обеим осям, прозрачность. Неправильный файл не попадает
   в очередь отдельных принтов; автоотправка остаётся на паузе.
6. Принятый готовый PNG не раскладывается повторно и не изменяется. Бот показывает
   новый предпросмотр и начинает новые 5 минут. «Отправить сейчас» отправляет раньше.
7. Чтобы отказаться от правок, редактор может нажать «Вернуть текущий макет».
   Текущий холст снова показывается и получает 5 минут на проверку.
8. «Проверить макет» в разделе ДТФ повторно открывает текущий предпросмотр.
   Обычный повторный просмотр не продлевает уже идущий таймер.

Старые кнопки предыдущей версии холста отклоняются. Изменение исходного состава
заказа делает старый предпросмотр недействительным. После начала передачи письма
редактировать эту отправку нельзя. Повторная доставка того же сообщения с готовым
PNG не создаёт отдельный принт и не создаёт новую отправку.

Исходные принты и прежний автоматически созданный PNG остаются в папке данных.
Новые файлы, пришедшие после начала подготовки заказа, остаются в следующей очереди.
При восстановлении связи одобренный холст повторно не раскладывается. Защита от
неопределённого результата SMTP и повтора уже отправленного письма сохраняется.
